🤖 Telegram Bot 設置指南
部署一個 Cloudflare Worker 作為 Bot 後端。發連結給 Bot → 自動抓取 Metadata → 儲存到 GitHub → 在 App 中下載同步。
1
到 Telegram 找 @BotFather，發送 /newbot 指令，創建機器人並記下 Bot Token
2
登入 Cloudflare Dashboard → Workers → 建立新 Worker，貼入以下代碼
3
在 Worker 設定 環境變數（Variables and Secrets）：
BOT_TOKEN、GITHUB_USER、GITHUB_REPO、GITHUB_PATH、GITHUB_TOKEN
4
複製 Worker 網址，在瀏覽器訪問以下網址設置 Webhook：
https://api.telegram.org/bot{TOKEN}/setWebhook?url={WORKER_URL}
5
在 App「設定 → GitHub 雲端同步」填好設定。以後只需把連結發給 Bot，再點「⬇️ 載入」即可同步
